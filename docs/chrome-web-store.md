```

## Detailed Description (up to 16,000 characters)
```
🚀 Supercharge your Google Gemini experience with keyboard shortcuts!

Google Gemini is an amazing AI assistant, but it lacks native keyboard shortcuts. This extension fills that gap, letting you navigate and control Gemini entirely from your keyboard.

═══════════════════════════════════
✨ KEY FEATURES
═══════════════════════════════════

⌨️ INSTANT SHORTCUTS
Press ⌘/ (Mac) or Ctrl+/ (Windows) anytime to see all available shortcuts in a beautiful overlay.

🔄 QUICK MODEL SWITCHING
Cycle through the available Gemini models with a single keystroke (⌘⇧M). No more clicking through menus!

🌓 THEME TOGGLE
Switch between System, Light, and Dark themes instantly (⌘⇧L).

🕶️ TEMPORARY CHAT
Toggle Gemini's temporary chat mode for one-off conversations (⌘⇧P).

📋 COPY RESPONSES
Copy the AI's latest response to your clipboard with one shortcut (⌘⇧C).

⚙️ FULLY CUSTOMIZABLE
Don't like the default shortcuts? Record your own! Click on any shortcut in the settings page to customize it.

🔄 SYNC ACROSS DEVICES
Your shortcut preferences automatically sync across all your browsers via Chrome Sync.

═══════════════════════════════════
📋 DEFAULT SHORTCUTS
═══════════════════════════════════

GEMINI BUILT-IN:
• New Chat: ⌘⇧O (Ctrl+Shift+O)
• Search Conversations: ⌘⇧K (Ctrl+Shift+K)

EXTENSION SHORTCUTS:
• Show Help: ⌘/ (Ctrl+/)
• Focus Input: /
• Toggle Sidebar: ⌘⇧S (Ctrl+Shift+S)
• Toggle Model: ⌘⇧M (Ctrl+Shift+M)
• Stop Generation: Esc
• Copy Last Response: ⌘⇧C (Ctrl+Shift+C)
• Toggle Theme: ⌘⇧L (Ctrl+Shift+L)
• Toggle Temporary Chat: ⌘⇧P (Ctrl+Shift+P)

═══════════════════════════════════
🛡️ PRIVACY & PERMISSIONS
═══════════════════════════════════

This extension:
✓ Only runs on gemini.google.com
✓ Does NOT collect any personal data
✓ Does NOT track your conversations
✓ Does NOT send data to external servers
✓ Uses storage permission ONLY to save your shortcut preferences

We believe in transparency. The extension is open source - you can review the code anytime.

═══════════════════════════════════
💡 HOW TO USE
═══════════════════════════════════

1. Install the extension
2. Go to gemini.google.com
3. Press ⌘/ (or Ctrl+/) to see all shortcuts
4. Start using shortcuts to speed up your workflow!

To customize shortcuts:
1. Click the extension icon
2. Click "Settings"
3. Click on any shortcut to record a new key combination
